# CA Server

Este repositorio contiene el código del backend de Cabildo Abierto, usado por el sitio web https://cabildoabierto.ar, hecho con (ExpressJS)[https://expressjs.com/].

Para habilitar el registro de cuentas, definí `REGISTRATION_PASSWORD` en el archivo `.env`. Quienes creen una cuenta deberán ingresar ese mismo valor como contraseña de registro.
